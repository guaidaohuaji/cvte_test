# Step15 风机自动调速优化报告

## 1. 源码审计结论

已确认step14中原本存在100%启动加力：

- `Core/Src/app_fan.c::handle_fresh_enable()`在风机从禁用切换到启用时，先施加`APP_FAN_MAX_DUTY_X100`，即100% PWM；
- `Core/Inc/app_fan_config.h`中原配置为`APP_FAN_STARTUP_BOOST_MS = 2000U`；
- 加力结束后，`AppFan_Process()`切换到调用者要求的目标占空比；
- 自动控制原本先请求固定30%目标占空比，因此实际过程为“100%加力2秒，再落到30%”；
- 加力结束后，自动控制每1000 ms只按固定1%增减；
- 原进入容差范围为±100 RPM，没有退出迟滞和误差方向连续确认。

## 2. 修改计划与实际实施

本次按“启动加力 + 查表前馈 + 小步闭环修正”实施，并保持W2协议、自动控制快照布局、风门控制、温度目标计算和带通测速数据路径不变。

### 2.1 启动加力

`APP_FAN_STARTUP_BOOST_MS`由2000 ms改为5000 ms。

风机每次从真正禁用状态启动时：

1. 物理PWM立即输出100%；
2. 保持5秒；
3. 加力期间允许自动控制更新“加力结束后要落到的目标占空比”；
4. 5秒结束后一次性切换到查表前馈占空比。

该机制沿用原`AppFan`架构，因此手动模式下从禁用到启用也使用5秒启动加力。

### 2.2 转速-PWM标定表

新增`Core/Inc/app_auto_fan_profile.h`，使用用户给出的标定点：

| RPM | PWM |
|---:|---:|
| 1000 | 10% |
| 1200 | 15% |
| 1400 | 20% |
| 1700 | 30% |
| 1900 | 40% |
| 2100 | 50% |
| 2200 | 60% |
| 2300 | 80% |

相邻点之间采用分段线性插值，随后按当前PWM硬件分辨率四舍五入到整数百分比。

典型结果：

| 目标RPM | 初始PWM |
|---:|---:|
| 1000 | 10% |
| 1100 | 13% |
| 1300 | 18% |
| 1500 | 23% |
| 1600 | 27% |
| 1800 | 35% |
| 2000 | 45% |
| 2150 | 55% |
| 2250 | 70% |
| 2300 | 80% |

正常闭环占空比限制为10%～80%；100%保留给启动加力和无测速故障保护。

### 2.3 前馈触发条件

以下情况直接重新查表定位：

- 从MANUAL切换到AUTO后的首次控制；
- 风机原本未启用；
- 目标转速相对上次前馈目标变化达到或超过100 RPM；
- 无测速故障恢复后重新获得有效测速。

小于100 RPM的目标变化不会反复覆盖已学习的闭环修正，而是交给后续小步闭环处理。

### 2.4 闭环微调

控制周期仍保持1000 ms，避免同时改变过多时间参数。

| 转速误差绝对值 | 单次占空比修正 |
|---:|---:|
| ≤120 RPM | 1% |
| 121～250 RPM | 2% |
| >250 RPM | 3% |

误差不超过250 RPM时，要求连续2次控制决策方向相同后才执行修正；误差大于250 RPM时立即修正。

控制决策即使只是完成第一次方向确认，也会推进1秒控制节拍，避免主循环在同一毫秒内快速累积两次确认。

### 2.5 容差迟滞

- 进入容差：误差≤50 RPM；
- 已进入容差后，误差≤80 RPM继续保持；
- 误差>80 RPM才退出容差并重新调节。

这可降低状态在“调节中/进入容差”之间反复切换。

### 2.6 测速新鲜度修复

审计发现原代码在PWM改变后调用软重捕获，但没有同步当前反馈`update_seq`。主循环顺序是：

`AppFan_Process()` → `AppFanFeedback_Process()` → `AppAutoControl_Process()`

因此PWM刚改变后，下一轮可能把改变前刚生成的测速结果误认为改变后的新测速。

本次在普通占空比变化和100%启动加力结束时均同步当前反馈序列，只有后续真正的新序列才可重新置为有效测速。

## 6. 建议硬件验证

1. 自动模式，目标约1000 RPM：确认启动后100%保持约5秒，再下降到约10%；
2. 目标约1500 RPM：加力结束后应直接落到约23%，而不是30%后逐秒下降；
3. 目标约1800 RPM：初始约35%；
4. 目标约2100 RPM：初始约50%；
5. 目标约2300 RPM：初始约80%，正常闭环不得升到100%；
6. 从1000 RPM目标切换到2100 RPM：应直接重新定位到约50%；
7. 目标小幅变化小于100 RPM：不应反复重置到查表值；
8. 观察进入容差后，在±80 RPM内不应频繁重新调节；
9. 断开FG：仍应进入100%故障保护；FG恢复后应重新查表回到正常占空比；
10. 记录达到目标所需时间、最大超调、最终占空比和稳定RPM。

## 7. 主要风险

- 5秒100%启动加力比原2秒更强，可能产生更明显的短时噪声、风量和转速超调；这是按用户要求实施，建议实机确认电源和风机允许连续5秒100%；
- 标定表来自当前样机，供电、电阻、风阻、温度和个体差异会改变对应关系，但闭环修正会补偿一定偏差；
- 2300 RPM附近曲线已接近饱和，80%之后收益很低，因此正常控制限制80%，不会为几十RPM误差追到100%；
- 中小误差采用2次同方向确认，最坏会增加约1秒，但用于降低测速波动导致的反向抖动。
