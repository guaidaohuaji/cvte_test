# Step26 术语与单位表

| 名称 | 含义 |
|---|---|
| `duty_x100` | 0.01%单位；100=1%，10000=100% |
| `temp_centi_c` | 0.01°C单位；2534=25.34°C |
| `freq_millihz` | 0.001 Hz单位；50000=50 Hz |
| `age_ms` | 当前快照距离最后有效更新的毫秒数 |
| Snapshot | 模块对外提供的当前事实副本，不是控制命令 |
| target | 请求或控制目标 |
| applied/actual | 已实际写入硬件或由硬件测得的值 |
| settling | 控制变化后的暂态等待窗口，期间不做故障判断 |
| suspect | 异常候选已开始计时，但尚未锁存 |
| latched | 故障已经锁存，短暂恢复不会自动清除 |
| guard | 单总线换向/帧间保护时间 |
| context | Master为某个从机地址保存的独立链路与结果记录 |
| `PSC` | 定时器预分频寄存器；实际除数为 PSC+1 |
| `ARR` | 自动重装寄存器；周期计数为 ARR+1 |
| `CCR` | 捕获/比较寄存器；输出时决定脉宽，输入时保存时间戳 |
| BPF | Band-Pass Filter，带通滤波器 |
| Legacy | 保留的旧测速链，用于回退和交叉诊断 |
| W2 | USART1上的 7E/A1/A2 上位机二进制协议 |
| 单总线 | 本工程USART6经外部单线电路实现的主从协议，不是Dallas 1-Wire |
