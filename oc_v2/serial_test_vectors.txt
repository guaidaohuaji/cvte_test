A1 帧布局 (23 字节):
[0]  status          (0x00=OK)
[1]  object_id       (0x07)
[2]  damper_state    (0x00=UNINIT, 0x01=POS_UNKNOWN, 0x02=FWD, 0x03=REV, 0x04=IDLE_REL, 0x05=POST_HOLD, 0x06=STOPPED, 0x07=FAULT, 0xFE=UNAVAIL)
[3]  flags           (bit0=pos_valid, bit1=moving, bit2=dir, bit3=released, bit4=estimated)
[4..7]   current_steps     int32 LE
[8..11]  target_steps      int32 LE
[12..15] remaining_steps   uint32 LE
[16..17] full_travel       uint16 LE
[18..19] configured_pps    uint16 LE
[20] last_command    (0x00=NONE, 0x01=ABS, 0x02=REL)
[21] last_result     (0x00=SUCCESS, 0x01=ABRT_STOP, 0x02=ABRT_REL, 0x03=ABRT_EMERG, 0x04=HW_ERR, 0x05=IN_PROG)
[22] fault_flags     (bit0=emergency, bit1=internal_range)

A2 子命令:
0x01 MOVE_ABSOLUTE      DATA len=6: 07 01 + target_int32_LE
0x02 MOVE_RELATIVE      DATA len=6: 07 02 + delta_int32_LE
0x03 STOP               DATA len=2: 07 03
0x04 RELEASE            DATA len=2: 07 04
0x05 SET_CUR_POS        DATA len=6: 07 05 + pos_int32_LE

frame_buf 索引:
  线上: 7E | TYPE | LEN | DATA[0]...DATA[n-1] | CSUM
  buf:  —  | [0]  | [1] | [2]...[1+n]         | [2+n]
  data[0] = 对象 ID
  data[1] = 子命令 (A2)

验证方式:
  A1/A2 响应帧: 由 SendW2Frame/send_error 构帧路径核对
  A1/A2 请求帧: 独立十六进制校验计算验证
